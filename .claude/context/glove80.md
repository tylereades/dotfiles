# Glove80 keyboard

Tyler uses a Glove80 (ZMK firmware) and is customizing its keybindings.
Working repo: `~/Projects/glove80-zmk-config` (his fork of
`moergo-sc/glove80-zmk-config`) — see that repo's own `CLAUDE.md` for the
build pipeline and standing workflow, and its `docs/keybinding-options.md`
for parked ideas not yet applied (Cmd+Tab swapper, home row mods, and notes
on alternative letter layouts like Colemak-DH/Engram/Graphite). Check there
before re-deriving Glove80/ZMK context from scratch, even in a session that
isn't `cd`'d into that repo.
